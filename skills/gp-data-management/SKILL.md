# gp-data-management

At most 2 pages (GRANT-FORMAT F13). Every product, repository, license
and size it names must exist and be checked.

## Procedure

1. **Inventory the products** from the description and the PI's repos:
   - manuscripts;
   - software (repo names and licenses, from each repo's LICENSE file);
   - databases (size from `du`; the destination, e.g. LMFDB with its
     review process);
   - video and lectures.
2. **Write four headed sections:**
   - **Types of products** — a numbered list naming each.
   - **Where and when each is shared** — arXiv on submission; GitHub
     from the first commit, with the license; Zenodo DOI for releases
     tied to papers; LMFDB after editorial review; data public at
     publication (cite the current NSF/DMS data supplement); YouTube.
   - **Formats and documentation** — package specs, schemas, plain-text
     records, README files.
   - **Access, preservation and reuse** — open access, mirrors, no human
     subjects, and a note on any proprietary software (e.g. Magma) with
     the open fallback.
3. URLs are allowed here (unlike the description). Use them for the
   repositories named only in words in the description.
4. **Research.gov may require the DMSP web tool** instead of a PDF for
   submissions after 2026-04-27. Check the form in `gp-researchgov`, and
   paste the same text if so.
5. Build it, confirm it is at most 2 pages, and upload it.
