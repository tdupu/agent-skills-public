# pd-ai-statement

Funders now expect proposers to disclose generative-AI use in the Project
Description; check the current PAPPG and solicitation for the exact rule.
The statement follows the manuscript AI-policy rules (model, harness and date
on every AI mention; AI-results declared; starting material named; models as
origin, never warrant; human responsibility; self-disclosure) adapted to a
proposal.

## Gather first

- The project's master AI-usage and token records, dated AI packages,
  commit trailers and agent commit authors, issue-tracker history.
- From the PI: which ideas came from which people (named), which were
  human-made and in what sense, which came from agent work.
- Count everything from the records; where a record is missing, say "not
  recorded".

## Paragraphs

1. **Software**: systems used substantively, each cited.
2. **Where the questions came from**: the human-built question library and
   data that preceded agent work, with dates and counts.
3. **How AI entered**: the timeline (from the records), the unit of work
   (e.g. a dated package with prompt, inputs, output, review, records), the
   models and harnesses, and how agent text is marked in the working notes.
4. **Where the ideas in this proposal came from**: one sentence per idea —
   person or session, date, what was checked and by whom.
5. **This proposal**: models, harness and dates of drafting; what the PI did;
   how claims were checked; the "agents report" convention; responsibility.
6. **Self-disclosure**: who drafted this statement, with model, harness, date.

## Rules

- Never brag about volume (pages, lines, sessions); describe the procedure
  that makes the output reliable.
- Never present agent review as human verification.
- Placement follows the PI (default: end of the background section).
