---
name: doc-pack-skills
description: Use when documenting a Claude/Codex skill collection, plugin pack, skill manifest, generated bundle, or skill installation surface.
---

Read the documentation contract and `superpowers:writing-skills` conventions.
Inspect each canonical `skills/<name>/SKILL.md`, pack catalogue, plugin
manifest, license, attribution, source register, builder, and generated
bundle. Document install/discovery, trigger examples, component scope,
canonical-versus-generated ownership, version/date, provenance, limitations,
and roadmap.

Check that every catalogue entry exists, descriptions are trigger-oriented,
links resolve, and a fresh build reproduces the bundle. Keep pack overview
short and link to leaves. Do not edit generated copies as source. Return the
file list, digest/build evidence, and any missing or stale skill.
