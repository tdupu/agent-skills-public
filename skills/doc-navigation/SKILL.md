---
name: doc-navigation
description: Use when repairing documentation links, indexes, parent-child navigation, orphan pages, duplicate canonical explanations, or stale tables of contents.
---

Read the documentation contract. Build a small link graph from entry points to
quickstart, examples, API/reference, development/operations, provenance,
limitations, and roadmap. Find broken links, orphan pages, duplicate homes,
stale catalogue rows, and links that expose private paths.

Prefer one canonical home per topic. Add reciprocal parent/child links where
the repository convention expects them and update indexes from the source of
truth. Check relative links, anchors, generated-page conventions, and package
manifest names. Do not hide missing content by adding a link to nowhere.

Return the graph checks, changed paths, command/result evidence, and remaining
orphans or unavailable link checker.
