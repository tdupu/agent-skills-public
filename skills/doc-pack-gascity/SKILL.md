name: doc-pack-gascity
description: Use when documenting Gas City packs, rigs, formulas, beads, worker workflows, manifests, or source-to-index synchronization.
---

Read the documentation contract and local Gas City policies. Inspect pack
manifests, source registries, generated indexes, AGENTS/POWERS instructions,
skill links, install/update commands, and public versus private paths.

Document how to acquire/install a pack, discover its routes, run a minimal
example, validate source-to-index alignment, and understand status, ownership,
limitations, and planned work. Explain generated versus canonical files. Use
the existing `update-gascity-packs-from-source` workflow when it matches; do
not hand-edit generated indexes without checking their source.

Return drift evidence, changed paths, commands/results, and unavailable
Gas City services.
